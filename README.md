# Smart Inventory System (Full-Stack) 🚀

A comprehensive Smart Inventory Management System designed to bridge interactive user interfaces with a robust database for seamless product and category management.

## 🛠 Tech Stack

This project is built using a modern technology stack to ensure high performance and scalability:

### **Back-End**
* **C# & .NET Core API**: For building the core business logic and RESTful services.
* **ADO.NET**: Used for direct and efficient database communication and data operations.
* **SQL Server**: The primary relational database for storing product, category, and user data.

### **Front-End**
* **Angular**: The main framework for building a dynamic and responsive Single Page Application (SPA).
* **TypeScript & JavaScript**: For implementing front-end logic and interactivity.
* **Bootstrap 5**: For crafting a sleek, mobile-friendly, and responsive user interface.
* **FontAwesome**: For intuitive and interactive iconography.

## 📁 Project Structure

The repository is organized into two main directories:
1.  **SmartInventorySystemBackend**: Contains the .NET Core API code and ADO.NET data access layer.
2.  **SmartInventoryUI**: Contains the Angular source code, components, and styling.

## 🚀 Key Features
* **Full CRUD Operations**: Create, Read, Update, and Delete products and categories.
* **Image Management**: Seamlessly upload and preview product images.
* **Smart Categorization**: Dynamically link products to specific categories.
* **Responsive Design**: Optimized experience across all devices (Mobile, Tablet, and Desktop).

## ⚙️ How to Run
1. **Clone the repository**.
2. **Database Setup**: Update the Connection String in the Back-end `appsettings.json` to match your local SQL Server instance.
3. **Run Back-end**: Open the solution in Visual Studio and run the API project.
4. **Run Front-end**: Navigate to the `SmartInventoryUI` folder, run `npm install` followed by `ng serve`.
5. Open your browser at `http://localhost:4200`.
